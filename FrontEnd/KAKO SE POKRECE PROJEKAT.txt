Backend (prvi terminal):
dotnet run --project ../Backend/Backend/Backend.csproj --launch-profile https

Frontend (drugi terminal):
npm install
npm start

Otvorite http://localhost:4200.
Prijavite se admin nalogom na /login, zatim otvorite /admin/users ili /admin/posts.
JSON Server se vise ne koristi. Detalji i test komande su u README.md.
